# 🛍️ ShopEase – Online Shopping Website

ShopEase is a responsive e-commerce frontend demo built with **HTML5 and CSS3**. It presents an online shopping interface with product categories, product cards, prices, discounts, ratings, shopping benefits, promotional offers, and a newsletter subscription form.

## ✨ Features

- **Announcement Bar:** Highlights the mega shopping sale.
- **Navigation Bar:** Includes links to categories, products, deals, and contact information.
- **Product Search UI:** Provides a search input for visitors to enter product names.
- **Hero Banner:** Introduces the store and highlights the 50% off promotion.
- **Shopping Benefits:** Displays delivery, secure shopping, returns, and customer support information.
- **Product Categories:** Electronics, Fashion, Accessories, and Home & Living.
- **Promotional Banner:** Highlights special offers and discounts.
- **Featured Products:** Shows eight sample products with descriptions, ratings, prices, original prices, discounts, and stock labels.
- **Add to Cart UI:** Displays shopping buttons as part of the frontend design.
- **Newsletter Form:** Includes an email input and subscribe button.
- **Footer:** Contains quick links and customer-service links.
- **Responsive Layout:** Uses CSS Grid, Flexbox, and media queries for desktop, tablet, and mobile layouts.
- **Accessibility Basics:** Includes form labels, visually hidden labels, and visible keyboard focus indicators.

## 🧰 Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the webpage and its content |
| CSS3 | Styles the interface and visual elements |
| CSS Grid | Creates responsive category, product, and footer layouts |
| Flexbox | Aligns navigation, banners, and form elements |
| Media Queries | Adapts layouts to different screen sizes |
| CSS Gradients | Creates colorful banners and product backgrounds |

## 🚀 How to Run

1. Download or clone the project repository.
2. Keep `index.html` and `shoping.css` in the same folder.
3. Open the folder in Visual Studio Code or another code editor.
4. Open `index.html` in your web browser.
5. For live preview while editing, use the Live Server extension in Visual Studio Code.

## 📱 Responsive Design

CSS media queries adjust the page for different screen widths:

- **Desktop:** Multi-column product and category layouts.
- **Tablet:** Product and category grids adapt to narrower screens.
- **Mobile:** Navigation, banners, product cards, newsletter form, and footer reorganize for smaller screens.

## ⚠️ Project Limitations

This is a **frontend demonstration only**. It does not include a backend or JavaScript functionality.

- Product search does not perform a real product search.
- The cart buttons do not add products to a real cart.
- Newsletter submissions are not connected to an email service.
- There is no checkout, payment processing, login, or order management.
- The HTML forms use placeholder actions and do not store submitted information.
