# 🎉 FESTORA 2026 – College Fest Website

**FESTORA 2026** is a modern, responsive college fest website designed to showcase technical events, cultural activities, workshops, schedules, and student registration details.

The website features an attractive dark theme with purple gradients, interactive hover effects, and a clean layout to provide visitors with an engaging experience.

## 🌟 Features

- **Home Page:** Attractive hero banner with the fest name, date, and location.
- **About Section:** Introduction to FESTORA 2026 and event statistics.
- **Events Section:** Displays technical and cultural events using card layouts.
- **Workshops Section:** Showcases workshops and learning opportunities.
- **Schedule Section:** Displays the fest timetable.
- **Coordinators Section:** Provides information about event coordinators.
- **Rules Section:** Lists important festival guidelines.
- **Registration Form:** Allows students to enter their details and select events.
- **Responsive Design:** Adapts the layout to desktops, tablets, and mobile devices.
- **Smooth Scrolling:** Provides smooth navigation between sections.
- **Modern UI:** Uses gradients, rounded cards, and hover animations.
- **Accessible Forms:** Includes labels, focus indicators, and HTML form validation attributes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the website content |
| CSS3 | Styles the website and creates layouts |
| CSS Grid | Organizes event cards and content |
| Flexbox | Aligns navigation and other elements |
| Media Queries | Makes the website responsive |
| CSS Gradients | Creates attractive backgrounds |
| HTML Forms | Collects student registration details |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code to preview the website.

## 📱 Responsive Design

The website uses CSS media queries to adapt to different screen sizes.

- **Desktop:** Multi-column layouts for events and workshops.
- **Tablet:** Two-column card layouts.
- **Mobile:** Single-column layouts and vertically arranged form fields.
